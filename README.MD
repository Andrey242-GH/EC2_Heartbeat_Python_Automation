# EC2 Heartbeat Automation

A lightweight automation platform that generates heartbeat events and displays them through a web dashboard.

## Features

- Event generation
- GUID creation
- Timestamp tracking
- Flask dashboard
- EC2 deployment support
- JSONL event storage
